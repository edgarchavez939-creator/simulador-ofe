Equivalencias
Fórmulas de referencia

Tasa Efectiva → Efectiva

(1 + i_origen)^(n_destino/n_origen) - 1

Donde n es la fracción de año del período

Tasa Nominal → Efectiva

(1 + j/m)^(m·n) - 1

j = nominal, m = períodos de capitalización/año

Tasa Efectiva → Nominal

j = m · [(1 + i_ea)^(1/m) - 1]

i_ea = tasa efectiva anual

Diaria: 365  |  Semanal: 52

Bimestral: 6  |  Trimestral: 4

Formato del archivo Excel

El Excel debe tener exactamente estas columnas según el tipo de programa

Pregrado — 4 columnas

  1. Programa — nombre del programa
  2. Valor Pregrado — valor numérico de la matrícula (sin puntos ni $)
  3. Valor Idiomas — valor numérico, usar 0 si no aplica
  4. Semestres — duración del programa en semestres (ej: 8, 9, 10, 12)

Los semestres determinan el plazo automático del crédito LP. Los beneficios/descuentos los configura el asesor en la simulación.

Posgrado — 3 columnas

  1. Programa — nombre del programa
  2. Subnivel — debe ser exactamente: Doctorado, Maestría o Especialización
  3. Valor — valor numérico de la matrícula (sin puntos ni $)

Pasos para reemplazar el simulador en línea

Método recomendado — Upload directo (más fácil)

  1. Ve a tu repositorio en github.com
  2. Haz clic en Add file → Upload files
  3. Arrastra el nuevo index.html descargado — GitHub reemplaza automáticamente el existente
  4. Escribe un mensaje como Actualizar programas semestre vigente
  5. Haz clic en Commit changes
  6. Espera 1–2 minutos y recarga tu sitio

Notas importantes

  1. El archivo generado es una copia completa de este simulador con los programas actualizados — conserva todas las pestañas, el actualizador y las funcionalidades.
  2. La auto-lectura funciona cuando el simulador corre en GitHub Pages. Si lo abres localmente (file://), sube el index.html manualmente.
  3. Los beneficios, descuentos y el pago de contado los configura el asesor en cada simulación — no van en el Excel de programas.
